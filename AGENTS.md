# Orientações para agentes de IA

1. Trabalhar preferencialmente em branches de desenvolvimento.
2. Nunca executar merge na branch `main` automaticamente.
3. Não modificar configurações do Ubuntu sem autorização explícita do usuário.
4. Testar os scripts antes de preparar commits.
5. Não incluir senhas, tokens ou outras credenciais no Git.
6. Preparar commits e Pull Requests somente quando solicitado pelo usuário.
7. Explicar as alterações realizadas e apresentar os resultados dos testes.
